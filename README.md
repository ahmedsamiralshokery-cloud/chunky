# Smart POS — نظام الكاشير الذكي

نظام كاشير مطاعم: فواتير، شاشة مطبخ، ورديات، تقارير، مدير/كاشير، وطلبات الأونلاين من الموقع.
كل البيانات بتتخزن في متصفح الجهاز اللي بيشتغل عليه الكاشير.

```
index.html              الصفحة
css/style.css           التنسيقات
js/app.js               كل منطق النظام
js/tailwind-config.js   إعدادات Tailwind
icons/                  أيقونات التطبيق
img/logo.png            الشعار
manifest.webmanifest    تثبيت التطبيق (PWA)
restaurant_pos.html     نسخة في ملف واحد (تفتح بدبل كليك بدون سيرفر)
sw.js                   التشغيل بدون إنترنت
```

## الرفع على GitHub Pages
1. اعمل Repository جديد (مثلاً `casher`).
2. ارفع كل الملفات والمجلدات دي في أول الـ repo.
3. Settings ← Pages ← Deploy from a branch ← `main` / `(root)` ← Save.
4. بعد دقيقة تقريباً: `https://USERNAME.github.io/REPO/`

## أول استخدام
- ادخل بـ **المدير** والرمز **1234** وغيّره فوراً من لوحة الإدارة ← الكاشير.
- أضف الكاشيرات واختار لكل واحد: كاشير (بدون لوحة الإدارة) أو مدير.
- البيانات محلية لكل جهاز: خد نسخة احتياطية دورياً من **البرنامج والذاكرة** (للمدير).

## بدون إنترنت
بعد أول فتح بإنترنت، الـ Service Worker بيحفظ الملفات والمكتبات وبيفتح النظام بدون إنترنت.
عند تعديل أي ملف، غيّر `VERSION` في `sw.js` علشان الأجهزة تاخد النسخة الجديدة.

## طلبات الأونلاين
المدير ← **طلبات الأونلاين** ← **إعدادات الربط**: إعدادات مشروع Firebase (`casher-system-44995`) واسم المجموعة (`orders`) متعبية جاهزة.
اكتب إيميل وباسورد حساب الكاشير (من Firebase Authentication) وفعّل الاستقبال واحفظ.
الباسورد بيتحفظ في المتصفح بس، مش داخل الملفات.
