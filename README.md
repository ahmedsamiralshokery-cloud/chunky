# CHUNKY - Fried Chicken & Burger | كفر الدوار 🍗🍔

موقع منيو وطلبات مطعم **تشانكي (CHUNKY)** في كفر الدوار، مبني بأحدث التقنيات:
- **React 19 + TypeScript 5**
- **Tailwind CSS v4**
- **Zustand** (حفظ السلة وبيانات العميل والمنيو تلقائياً)
- **Vite PWA** (يعمل بدون إنترنت مع إمكانية التثبيت كتطبيق)
- **GitHub Actions** للنشر التلقائي على GitHub Pages

## وضع الصور في المشروع
ضع الصور المرفقة في مجلد `public/images/` بالأسماء التالية:
- `logo.jpg` (صورة شعار CHUNKY الأصفر)
- `banner.jpg` (صورة 6 سنين قرمشة)
- `offer-1.jpg` (عرض تشانكي 1#)
- `offer-2.jpg` (عرض تشانكي 2#)
- `offer-3.jpg` (عرض تشانكي 3#)

## التشغيل محلياً
```bash
npm install
npm run dev
```
